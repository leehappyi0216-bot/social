# 중1 사회 공부방

중학교 1학년 사회①(미래엔) 학습 사이트입니다. 서버·로그인 없이 HTML/CSS/JS만으로 동작합니다.

## 기능
- **학습 대시보드**: 연속 학습일, 오늘의 목표(20문제·카드), 이어서 학습, 약한 단원 추천, 단원별 숙련도 링
- **단원별 핵심 요약**: 교과서 중단원 순서·용어 그대로 정리(`심화` 표시는 교과서 밖이지만 학교 시험에 나온 내용)
- **퀴즈**: O/X·객관식·빈칸, 즉시 채점과 해설, 키보드 단축키(O/X, 1~4)
- **서술형 대비**: 학교 정기시험 형식(제시문·배점·채점 기준·문장형식 감점) 자동 채점
- **용어 카드**: 간격 반복(1일 → 3일 → 7일 → 14일), 하루 새 카드 20장, 스페이스바로 뒤집기
- **실전 모의고사**: 시험 범위·문항 수·제한 시간을 골라 서·논술형을 한 번에 풀고 일괄 채점, 기록 저장
- **검색**: 용어·요약·서술형 문제 전체 검색
- **오답 노트**: 퀴즈·서술형·모의고사에서 틀린 문제 자동 저장, 맞히면 삭제
- 숙련도 = 퀴즈 최고 점수 35% + 서술형 최고 점수 40% + 용어 카드 암기(3단계 이상) 25%

## 실행
- 가장 간단한 방법: `index.html`을 더블클릭해 크롬/엣지에서 열기
- 로컬 서버로 보기: `powershell -ExecutionPolicy Bypass -File serve.ps1` → http://localhost:5500

## 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `css/style.css` | 디자인 (다크 모드·모바일 대응) |
| `js/app.js` | 화면 전환, 퀴즈 채점, 점수·오답 저장 |
| `js/data.js` | **단원 내용과 문제** (여기만 고치면 내용이 바뀜) |

## 내용 고치기 / 문제 추가하기
`js/data.js`에서 해당 단원의 `quiz` 배열에 추가합니다.

```js
{ type: "ox", q: "문제", a: true, ex: "해설" }                         // O/X
{ type: "mc", q: "문제", choices: ["가","나","다","라"], a: 0, ex: "해설" } // 객관식 (a: 정답 번호, 0부터)
{ type: "blank", q: "빈칸은 ___ 처럼 표시", a: ["정답", "다른 인정 답"], ex: "해설" } // 빈칸
```
요약 문장 안에서 `**단어**`로 감싸면 굵게 강조됩니다.

## 서술형 문제 고치기
`js/essay.js`(기본 문항), `js/essay-extra.js`(추가 문항), `js/essay-extra2.js`(10~12단원 추가 문항)에서 단원 id(g1~g6, c1~c6)별로 추가합니다. 학교 정기시험 서·논술형 형식(제시문 밑줄, 배점, 채점 기준, 부분점수 없음, '~다' 문장형식이 아니면 1점 감점)으로 채점합니다.

```js
{ q: "발문",
  passage: "제시문. __(가) 밑줄__ 표시",          // (선택)
  box: "① 설립 목적  ② 사회화 내용",             // (선택) <보기>
  similar: false,                                  // (선택) '유사 답안 인정' 숨김
  parts: [
    // 항목마다 답안 칸 1개. 핵심어 묶음을 모두(또는 need개) 맞히면 pts점
    { label: "(가)", pts: 3, a: "모범 답안이다.", k: [["역할모순", "모순"]] },
    // 'N가지 서술' 문항: 맞힌 가지 수 × pts점
    { label: "해결 방안", n: 2, pts: 2, options: [
      { a: "관용의 태도를 기른다.", k: [["관용", "존중"]] },
      { a: "차별 금지 제도를 만든다.", k: [["법", "제도"]] } ] }
  ] }
```
핵심어 `k`는 묶음 배열이고, 묶음 안 낱말 중 하나만 들어 있어도 그 묶음을 맞힌 것으로 봅니다. 띄어쓰기는 무시합니다.

## 알아둘 점
- 대단원명과 요약의 소제목(중단원명)은 미래엔 사회①(2022 개정) 목차에 맞췄습니다.
- 1~12단원 전체의 요약·퀴즈·서술형 용어를 미래엔 교과서 견본(웹용) 본문과 대조해 맞췄습니다. 지리 서술형은 `js/essay-geo.js`에 있습니다.
- 교과서 본문에 없는 용어(탈사회화, 역할 모순·긴장, 필터 버블, 딥페이크, 문화 절대주의 등)는 학교 시험에 나와서 `심화`로 표시해 남겨 두었습니다.
- 점수와 오답은 **각 학생의 브라우저에만** 저장됩니다(다른 기기와 공유되지 않음).
- 교과서 본문·사진은 넣지 않고 직접 정리한 요약만 담았습니다.
